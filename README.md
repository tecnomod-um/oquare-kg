# OQuaRE-KG 
OQuaRE-KG[^1] is a quality framework for assessing KGs inspired on the [OQuaRE](https://github.com/tecnomod-um/oquare) [^2] framework for ontology quality.

![The OQuaRE-KG framework, characteristics and their associated subcharacteristics:](https://github.com/tecnomod-um/oquare-kg/blob/main/framework/images/OquareKG.png)
