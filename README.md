# OQuaRE-KG 
OQuaRE-KG[^1] is a quality framework for assessing KGs inspired on the [OQuaRE](https://github.com/tecnomod-um/oquare) [^2] framework for ontology quality. A detailed description of the whole framework can be found in the next sections:
* [The framework](./framework/README.md)
    * [Quality characteristics](./framework/characteristics.md)
    * [Quality subcharacteristics](./framework/subcharacteristics.md)
    * [Metrics](./framework/metrics.md)
* [Evaluation experiments](./evaluation/README.md)
* [The oquarekg Python Package](./oquarekg_package/README.md)
