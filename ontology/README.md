# The oquo-oquare-kg ontology
The [oquo-oquare-kg](https://purl.archive.org/oquo-oquare-kg) ontology extends the Ontology QUality Ontology ([OQUO](https://github.com/tecnomod-um/oquo)) by including the OQuaRE-KG framework[^oquarekg].



[^oquarekg]: [Juanes-Cortés, B., Mulero-Hernández, J., & Fernández-Breis, J. T. (2026). OQuaRE-KG: an OQuaRE inspired framework for knowledge graph quality assessment. 1st International Workshop on Quality in Large Language Models and Knowledge Graphs (QuaLLM-KG)](https://ceur-ws.org/Vol-4192/QuaLLM_KG-paper2.pdf)
