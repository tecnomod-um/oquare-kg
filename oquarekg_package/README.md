# OQuaRE-KG

OQuaRE-KG is a quality evaluation framework for assessing knowledge graphs based on OQuaRE.

## Installation

```bash
pip install git+https://github.com/tecnomod-um/oquare-kg.git#subdirectory=oquarekg_package
```

# Usage

## Command-line execution

```bash
Complete workflow: python ......
```

```bash
Calculate metrics: python ......
```

```bash
Calculate scores: python ......
```

## Command-line parameters

* graph_file: name of the file that contains the graph to evaluate.
* domain_uri: no sé qué representa exactamente
* input_dir: direc. This parameter is only needed when running for calculating the scores only. This is the directory that stores the metrics generated by OQuaRE-KG.
* output_dir: directory for saving the files generated by the OQUARE-KG execution.

# Sample code

## Complete workflow

```Python
from oquarekg import run_oquarekg

run_oquarekg(

    graph_file="graph.ttl",

    domain_uri="http://example.org"

)
```

## Evaluation only

```Python
from oquarekg import evaluate

evaluate(

    graph_file="graph.ttl",

    domain_uri="http://example.org"

)
```

## Scoring only

```Python
from oquarekg import scoring
scoring(
    input_dir="results",
    output_dir="results"
)
```
